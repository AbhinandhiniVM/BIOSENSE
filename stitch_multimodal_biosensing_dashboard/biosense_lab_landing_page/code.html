Workflow

From Sensor Boot to Published Data

Zero-configuration scientific pipeline built for lab benches and field studies alike.

01

Pair Sensor Node

Instant hardware handshake via USB-C or low-latency BLE 5.3 broadcast beaconing.

02

Impedance & Calib

Automated lead impedance checks (<5kΩ target) and static gravity vector auto-tare.

03

Stream Multi-Modal

Hardware-synchronized 1,000 Hz frame interleaving across biopotentials, optical, and motion.

04

Run Neural Models

Execute on-device pulse transit time, frontal alpha asymmetry, and cognitive load filters.

05

Export Research Data

One-click streaming via Lab Streaming Layer (LSL), raw EDF, HDF5, and tidy-formatted CSVs.
